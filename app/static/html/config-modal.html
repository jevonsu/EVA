Agent 角色设定

① 身份与人设：名称、语言、角色背景；需要沉浸时打开「启用角色扮演」。 工作方法见 ②～⑥。超长手册放知识库 / 工作流。

① 身份与人设 谁 · 怎么说话 · 要不要沉浸扮演

基础身份 名称 · 语言 · 角色背景

角色扮演（可选 · 展开填写人设） 未启用
运行参数（工具轮次 · 历史上限 · 会话演化）

会话演化：达到触发条数后把更早内容压成摘要并注入后续对话，避免长聊遗忘关键结论。

② 隐性决策树 内部判断路径 · 不直接对用户复述
③ 动态语言校准器 如何随场景调节语气与措辞
④ 标准化作业流程（SOP） 可复用的分步工作法
⑤ 硬性边界 通用红线 · 不可突破
⑥ 通用开机语 新对话默认开场；同时写入人设
系统固定规则（只读 · 不可在此改）

  工具开关
 

 此处为 LLM 实际可调用的函数（function calling）。
 数据源 /api/config/tools。开关即时生效；下方可加自订 HTTP 工具。
 

 

 Skill = 能力包，Tool = 可调用接口。多数 Skill 会注册 1 个 Tool，
 两个面板数字不要相加。角标「主入口 / 等价 / 后备」仅作推荐指引。
 分组默认折叠，点标题展开。

  Skills
 

 此处为 能力包目录（安装/开关单元），不是 LLM 直接调用的函数名。
 数据源 /api/config/skills · 目录 skills/<id>/。
 

 

 关闭某个 Skill 会卸载其注册的 Tool；开启后重新出现在 Tools 列表。
 与 Tools 面板数字不叠加。分组默认折叠，点标题展开。

  扩展能力（MCP）
 

 给助手外挂更多本事（网页、文件夹、Git…）。点预设即可添加，一般不用写代码。
 多数预设需要本机已安装 Node.js。
 

 

 

 
 
 

 

 

 

 
一键添加（推荐）

 
点一张卡片 → 自动填好并保存连接。成功后可在对话里用到新能力。

 

 


 
已添加的扩展

 

 


 
 

 

 

  集成连接
 

 技能（NocoDB / NAS / qB / HTTP 代理等）的连接参数。存于 config.json → integrations，
 前端可增改删，无需手改文件。密码/Token 脱敏；留空保存表示不修改已有密钥。
 

 

 Skills 面板可看到是否已配置；调用技能时实时读取此处配置。

 旧版 reminders 已停用。

 浏览 workspace/。可上传/下载、在线编辑文本、新建/删除。

  Webhook 通道
 

 为每个外部平台建一条通道，各自独立 Token，并绑定不同对话。
 调用 POST /api/webhook/{slug}/chat，请求头 X-Webhook-Token。
